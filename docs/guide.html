2. The 9 Canonical Seats & Phase Gates (Including Documentation Parity)

Every Crew Bank maps 9 distinct characters onto 9 canonical engineering seats across a 4-stage pipeline:

  1. Phase 1 -- Recon & Trench Diagnostics (🔵 Seat 1A recon + 🟠 Seat 1B diagnostics): Reads the actual source contract first and traces any bug to its exact file:line coordinate.
  2. Phase 2 -- Architecture & The Alignment Gate (🟣 Seat 2 architect): Maps state invariants, contract boundaries, and concurrency seams, and waits for your green light before turning the Blitz seat loose.
  3. Phase 3 -- Full-Depth Blitz, Parallel Overwatch & Documentation Parity (🔴 Seat 3 blitz + 🟢 forensics + ⚡ velocity + 🛡️ redteam + 🎨 ergonomics): Implements the complete change at full depth (never a skeleton), watches the regression test fail red on the unfixed state before restoring the fix, audits security/artifacts/latency/UX, and checks and updates README.md, docs/, and CLI --help for documentation parity in the same pass.
  4. Phase 4 -- The Archive (📓 Seat 5 archivist): Records the inflection point onto the sequential tape (#seq), updates the project state head, and reconciles open vs. resolved threads.

3. Collaborator Project Sync vs. Non-Collaborator Personal Comms (@comms)

Construct supports two distinct encrypted W3C did:key + Stateless Epoch-Keyed AEAD (HKDF-SHA256 + ChaCha20-Poly1305 + Ed25519) + HLC-CRDT connection modes over zero-signup WebSocket relays (wss://nos.lol, wss://relay.damus.io, or self-hosted construct relay). Unlike stateful IETF RFC 9420 TreeKEM (which requires a central Delivery Service to order commits and deletes per-message keys immediately), Construct's Epoch-Keyed AEAD keeps CRDT delta packets decryptable out-of-order across multiple stateless store-and-forward relays:

Mode A: Project Collaboration Invite (construct invite <project>)

For teammates working on the same git repository:

# Alice creates a project invite
construct invite acme/alpha_app

# Bob joins (auto-clones repo if missing & syncs tape/gotchas)
construct join "construct://invite/eyJ...#..." --dir ~/src/alpha_app
construct sync acme/alpha_app

Syncs frames, project gotchas, heads, and person-to-person Courier messages for acme/alpha_app while enforcing strict per-project isolation (zero bleed from your other private repos or global gotchas).

Mode B: Non-Collaborator Personal Comms (construct invite comms)

For friends or colleagues who want to exchange in-character Courier Cameos (--via smeagol, --via death, --via toot, --via moist) without sharing any git repository:

# Alice creates a personal comms-only invite (no project repo!)
construct invite comms

# Carol joins (no --dir or workspace_root required, 0 git clone)
construct join "construct://invite/eyJ...#..."

# Send an in-character Courier message to Carol
construct msg --to carol --via smeagol "Ssshh! How is it working, precious?"

The @comms channel enforces a hard cryptographic boundary guard in src/crdt.js: only message and message_tombstone operations are exported or accepted on @comms; any frame, gotcha, or head operation is rejected at the boundary.
